# AI Learning Assistant

Final project for the Modern Data Engineering for AI Systems course.

## Project Overview
AI Learning Assistant is a simple course knowledge assistant that applies data quality checks, text chunking, embeddings, vector storage, semantic retrieval, and a RAG-style response flow.

## Pipeline

```text
Knowledge Base
    ↓
Data Quality Checks
    ↓
Chunking
    ↓
Embeddings
    ↓
ChromaDB
    ↓
Semantic Retrieval
    ↓
RAG-style Answer
```

## Tools
- Python
- Sentence Transformers
- ChromaDB
